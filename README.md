# Дерево Фенвика (Fenwick Tree) на Java

Реализация дерева Фенвика (Binary Indexed Tree) и консольное приложение для работы с ним. Дерево позволяет быстро считать суммы на отрезках массива и обновлять элементы. Обе операции выполняются за O(log n), а не за O(n), как при простом переборе.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=openjdk&logoColor=white)

Учебный проект по алгоритмам и структурам данных. По условию задания вспомогательные классы стандартной библиотеки (`Scanner`, `Arrays`) не использовались: чтение ввода, разбор чисел и работа с массивами написаны вручную.

## Операции `FenwickTree`

| Метод | Что делает | Сложность |
|---|---|---|
| `build(arr)` | строит дерево по массиву | O(n log n) |
| `update(i, delta)` | прибавляет `delta` к элементу `i` | O(log n) |
| `prefixSum(i)` | сумма элементов с 0 по `i` | O(log n) |
| `rangeSum(l, r)` | сумма на отрезке `[l, r]` | O(log n) |
| `findKthElement(k)` | k-й наименьший элемент, если дерево хранит частоты | O(log² n) |

Суммы хранятся в `long`, чтобы не было переполнения на больших массивах.

## Консольное приложение

`Main.java` позволяет работать сразу с несколькими массивами («проектами»):
- создавать, переименовывать, удалять проекты и переключаться между ними;
- объединять два массива в новый;
- считать префиксные суммы и суммы на отрезке;
- изменять, вставлять и удалять элементы, при этом дерево обновляется или перестраивается;
- смотреть текущее состояние массива и дерева.

## Запуск

Нужна Java 11+. Запускать нужно **из терминала**: программа читает ввод через `System.console()`, а во встроенной консоли IDE он недоступен.

```bash
javac -encoding UTF-8 *.java
java Main
```
